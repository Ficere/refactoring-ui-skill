# Refactoring UI 原则

一套写、改或审视产品界面时用的 20 条视觉规则，做成可直接加载的 Cursor skill（`SKILL.md`）。

规则精炼自 Adam Wathan 与 Steve Schoger 的 [*Refactoring UI*](https://www.refactoringui.com/)，取材口径参考龙海的文章 [人人都是 UI 设计师](https://x.com/longhaiqwe123/status/2106216781174251724)。本仓库是操作清单，不是原文摘录；请不要把文章或原书大段复制进产品或文档。

做网页前端时，建议与 `frontend-design` 一起使用。

## 使用

把 `SKILL.md` 放到 Cursor 的 skills 目录（例如项目内的 `.cursor/skills/refactoring-ui-principles/SKILL.md`，或个人 skill 库）。在设计或走查页面、dashboard、落地页和组件时加载它。

## 许可与来源

《Refactoring UI》的版权属于原作者。本 skill 只整理可执行的原则，供学习和实践使用。
